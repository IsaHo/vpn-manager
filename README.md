# VPN Manager — Xray REALITY + Telegram MTProxy

پروژهٔ مدیریت سرور شخصی با VLESS/REALITY، پروکسی تلگرام و بات مدیریتی فارسی.
هستهٔ ارتباطی Xray است؛ کلاینت باید VLESS + REALITY + Vision را پشتیبانی کند، مثل نسخهٔ جدید v2rayNG یا v2rayN.

## امکانات

- ساخت کاربران مستقل با UUID و تاریخ انقضا؛ حذف کاربران منقضی هر دقیقه.
- لینک VLESS و لینک مستقیم پروکسی تلگرام با random padding.
- بات با محدودیت شناسهٔ عددی مدیر و گفت‌وگوی خصوصی؛ تأیید عملیات حذف و restart.
- سرویس‌های systemd، بازیابی خودکار پس از خطا، و تازه‌سازی روزانهٔ اطلاعات upstream تلگرام.
- دانلود نسخهٔ ثابت Xray و منبع ثابت MTProxy با بررسی SHA-256؛ کلیدها روی سرور ساخته می‌شوند.
- بررسی تنظیمات با Xray قبل از اعمال و بازگرداندن تنظیمات قبلی در خطای restart.

این نسخه محدودیت حجم، محاسبهٔ مصرف، پنل فروش، چند سرور و تفکیک کاربران MTProxy ندارد.
لینک MTProxy مشترک است؛ حذف کاربر VLESS دسترسی او به MTProxy را لغو نمی‌کند.
تغییر کاربران باعث restart کوتاه Xray و قطع اتصال‌های جاری می‌شود.
قابلیت اتصال از هر اپراتور تضمین نمی‌شود؛ دسترسی به IP، REALITY target و تلگرام به شبکهٔ سرور وابسته است.

## پیش‌نیاز

Ubuntu 22.04/24.04 یا Debian 12 با systemd و معماری **amd64**، دسترسی root، IP عمومی و ساعت صحیح.
سرور باید به GitHub، مخازن apt، `api.telegram.org`، `core.telegram.org` و مقصد REALITY دسترسی داشته باشد.
MTProxy رسمی از دستورهای CPU خانوادهٔ x86 استفاده می‌کند؛ این نصب‌کننده ARM را قبول نمی‌کند.
نصب روی توزیع‌های ذکرشده در سرور مقصد هنوز باید بررسی شود؛ تست‌های محلی جای تست اتصال واقعی را نمی‌گیرند.

## نصب

مخزن پروژه را روی سرور clone کن، داخل پوشه برو و اجرا کن:

```bash
sudo bash install.sh
```

نصب‌کننده این موارد را می‌پرسد:

1. IP عمومی یا دامنهٔ سرور.
2. پورت VLESS، پیش‌فرض `8443`.
3. پورت پروکسی تلگرام، پیش‌فرض `9443`.
4. دامنهٔ TLS برای REALITY، پیش‌فرض `www.microsoft.com`؛ این دامنه باید TLS 1.3 معتبر و از سرور قابل دسترسی باشد. مالکیت این دامنه لازم نیست.
5. توکن بات از BotFather، به‌صورت مخفی در ترمینال.
6. شناسهٔ **عدد‌ی حساب مدیر**؛ نام کاربری یا ID خود بات کافی نیست.

بات باید اختصاصی این نصب باشد: long polling، webhook قبلی را حذف می‌کند و پیام‌های قدیمی را کنار می‌گذارد.
توکن و کلید خصوصی را در مخزن، چت یا فایل عمومی ذخیره نکن. نصب‌کننده فایل‌های محلی با دسترسی محدود می‌سازد.
اجرای دوبارهٔ نصب روی نصب موجود متوقف می‌شود تا کلیدها تغییر نکنند. اگر نصب ناقص شد، وضعیت را بررسی کن؛ state را بی‌دلیل حذف نکن.

در فایروال سیستم و پنل ارائه‌دهنده، دو پورت انتخابی را برای **TCP ورودی** باز کن. پورت SSH را باز نگه دار.
نصب‌کننده فایروال را تغییر نمی‌دهد. اگر UFW از قبل فعال است و پورت‌های پیش‌فرض را انتخاب کردی:

```bash
sudo ufw allow 8443/tcp
sudo ufw allow 9443/tcp
```

در این نصب، سوکت داخلی RPC و آمار MTProxy غیرفعال است؛ فقط پورت کلاینت پروکسی باز می‌شود.

## استفاده

داخل چت خصوصی بات، `/start` را بفرست:

```text
/status
/add phone 30
/list
/link phone
/delete phone
/confirm
/proxy
/restart xray
/confirm
```

نام کاربران ۱ تا ۳۲ کاراکتر لاتین، عدد، `_` یا `-` است. اعتبار ۱ تا ۳۶۵۰ روز.
توکن بات و شناسهٔ مدیر فقط هنگام نصب روی سرور وارد می‌شوند؛ این پروژه برای راه‌اندازی نیاز ندارد آن‌ها را برای توسعه‌دهنده بفرستی.
بات مجوز اجرای فرمان آزاد ندارد؛ فقط دستورات معین `vpnctl` از طریق sudo قابل اجرا هستند.

روی سرور نیز می‌توانی اجرا کنی:

```bash
sudo vpnctl status
sudo vpnctl add phone 30
sudo vpnctl proxy
sudo journalctl -u vpn-xray -u vpn-mtproxy -u vpn-bot -n 80 --no-pager
```

## نگهداری

فایل‌های حساس: `/var/lib/vpn-manager/state.json`، `/etc/vpn-manager/xray.json`،
`/etc/vpn-manager/mtproxy.args` و `/etc/vpn-manager/bot.json`.
نسخهٔ پشتیبان این فایل‌ها را در محل خصوصی نگه دار؛ حاوی کلیدها و دسترسی‌های فعال هستند.
برای تغییر توکن یا شناسهٔ مدیر، با root فایل `bot.json` را ویرایش و `vpn-bot` را restart کن.
کاربران منقضی هنگام پاک‌سازی حذف می‌شوند؛ برای تمدید باید کاربر را دوباره بسازی و لینک جدید بدهی.
هیچ به‌روزرسانی خودکار باینری انجام نمی‌شود؛ برای ارتقای Xray یا MTProxy باید نسخه، checksum و سازگاری بازبینی شود.

## بررسی توسعه

```bash
python3 -m unittest -v
bash -n install.sh
```

تست‌ها کنترل دسترسی بات، تأیید حذف، ورودی نامعتبر، چرخهٔ کاربران، انقضا و rollback را بررسی می‌کنند.
تست اتصال واقعی VLESS و MTProxy از بیرون سرور و اجرای systemd باید پس از نصب انجام شود.
نرم‌افزارهای Xray و MTProxy متعلق به پروژه‌های upstream هستند و مجوز مستقل دارند.
